2. Run the agent on your machine

Single Python file, standard library only. Reads your logs and ships matching lines — failed SSH logins, sudo escalations, new sessions. 

# download
curl -O /agent/argus-agent.py

# check connectivity (sends one event)
export ARGUS_API_KEY=<your key>
python3 argus-agent.py --test

# then tail your auth log
sudo -E python3 argus-agent.py --follow /var/log/auth.log

# or on a systemd host
journalctl -f | python3 argus-agent.py --stdin

Events appear on the Events tab within a second or two; matching rules raise alerts shortly after. Read the source — it is about 200 lines, and you should read anything you run as root.
